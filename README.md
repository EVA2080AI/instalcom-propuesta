# Propuesta INSTALCOM

Página de la cotización comercial (pre-diagnóstico, Personal y asistencia,
Gestión y evidencias de obra) para INSTALCOM SAS. Publicada con GitHub Pages
desde `index.html`. `robots.txt` pide a los buscadores no indexarla: es un
documento comercial para el cliente, no contenido público de marketing.

Fuente de la cotización (repo del proyecto, privado): `docs/comercial/` en
el repositorio de la plataforma INSTALCOM.
